
# Supply Chain Analytics Dashboard
## Project Documentation

## 1. Business Objective

The objective of this project is to develop an interactive Business Intelligence dashboard that provides management with visibility into supply chain operations and business performance.

The application supports data-driven decision-making through the analysis of sales, inventory, suppliers and order activity.

## 2. Data Sources

The application retrieves operational data from Microsoft SQL Server.

The analytical data domains include:

- Sales
- Products
- Inventory-related product records
- Suppliers
- Orders

## 3. Analytical Components

### Executive Performance
- Executive KPIs
- Financial performance monitoring

### Sales Analysis
- Revenue analysis
- Revenue contribution by category
- Product performance
- Monthly revenue trends

### Inventory Analysis
- Inventory valuation
- Stock monitoring

### Supplier Analysis
- Supplier activity
- Supplier performance insights

### Order Analysis
- Independent order performance analysis

### Reporting
- Excel report export

## 4. Technical Architecture

The application follows the architecture:

Microsoft SQL Server → SQLAlchemy → Pandas → Streamlit → Plotly

### Technologies

- Python: Application development
- Microsoft SQL Server: Data storage
- SQLAlchemy: Database connectivity
- Pandas: Data processing and analysis
- Streamlit: Dashboard interface
- Plotly: Interactive visualizations
- OpenPyXL: Excel reporting support

## 5. Business Value

The dashboard transforms operational database records into actionable business insights.

It supports management in:

- Monitoring financial performance.
- Evaluating product and category contribution.
- Understanding inventory valuation.
- Monitoring supplier activity.
- Evaluating order performance.

## 6. Application Validation

The application was launched successfully in a local environment.

Python syntax validation was also completed successfully.

## 7. Technical Requirements

The application requires:

- Python environment.
- Microsoft SQL Server database.
- Compatible Microsoft ODBC driver.
- Configured database connection.
- Installed Python dependencies.

Completed – Functional local application.
